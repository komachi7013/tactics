# 入力・出力と合格条件

## 入力確認表

|項目|必要な条件|
|---|---|
|制作対象|ID、人数、主人公・味方・NPC・敵の区分|
|外見|体格、服装、配色、持ち物、参考画像|
|アニメーション|必要な動作、方向数、フレーム数や容量制限|
|移動制作時|自由/グリッド、速度、論理入力、追従/巡回の要否|
|組み込み時|エンジン、画像形式、座標単位、縮尺、描画順、地形・照明接続|

外見や人数は呼び出し元から取得する。仕様提案・テスト設計を任された場合に限り仮定を記録して補う。

## 納品契約

プロジェクトの既存形式を優先する。未指定ならJSONとMarkdownを使用する。

- キャラクター一覧: `id`, `role`, `commonDataId`, `assets`, `worldHeight`, `pixelDensity`。
- アニメーション: `action`, `direction`, `frames`（画像またはセル番号）, `frameDurationMs`, `loop`, `idleFrame`, `footOrigin`。原点は出力セルの左上からのピクセル座標。
- 移動: `mode`, `speed`（単位/秒）, 論理入力、方向選択と静止時の向き、移動禁止状態。
- 衝突: 足元座標、円/矩形と寸法、他キャラとの重なり方針、壁沿い移動。グリッドの場合はセル予約、通行判定、移動中再入力のバッファ方針。
- 音声: 確定移動距離または接地フレームに同期した足音イベント、音声側ID、材質参照。テストでイベントのみなら音源未実装と明記する。

## マップとの境界

キャラクター位置は足元の地面座標。マップは通行領域、障害物、地面材質、前景遮蔽、照明と焦点条件を提供する。確定位置を描画・カメラへ渡し、スクリーン座標で衝突や速度を計算しない。描画順は共有基準（例: 足元Y + レイヤー）を使う。接地影は地面側で描き、素材に焼き込む陰影とランタイムの方向光を衝突させない。

`stop(reason)` で入力、歩行、足音を停止。`place(mapId, position, facing)` は停止状態で再配置し、入力解除後に再開する。非アクティブ化、会話、メニューも同じ停止契約を利用する。

追従・巡回は同じ地形判定を利用し、到達不能・経路閉塞では停止/再探索など指定の方針を使う。マップ遷移時は全対象を停止し、到着側の契約で再配置する。

## 検証記録

各項目を `pass / fail / not-tested / not-applicable` とし、根拠を添える。

歩行は `SKILL.md` の「歩行の必須合格条件」を適用する。指定された全方向で左右の脚が交互に前へ出ることを、エージェント自身がコマ比較と方向別ループで検証する。方向ごとの結果と確認したプレビューを記録し、不自然な足運びは納品前に修正する。ユーザーによる確認を合格条件の代替にしない。膝の曲げ方や靴の高さだけの変化、数値QCだけの合格は不可。

|区分|確認内容|
|---|---|
|素材|ID、方向、動作、透過、色にじみ、余白、欠け、体格、共有足元|
|アニメーション|フレーム順、再生速度、ループ、向き、歩行から待機、全方向の左右脚の交互接地と腕の逆位相。側面は手前の脚の腰→膝→すね→靴を追い、腰より前→後ろに切り替わることを確認。膝の曲げや靴の高さだけの変化を交互接地と判定しない。背面は左右の足の上下が切り替わることを確認。同じ脚が常に前に出る踏み出しは不合格|
|移動|30/60/144fpsの距離、斜め速度、停止、方向転換|
|衝突|壁、角、狭路、画面端、大きいdt/高速移動、壁沿い移動|
|制御|会話、メニュー、blur、遷移停止、到着位置・向き、往復後の再操作|
|音声|停止・阻害・禁止中の無発火、材質参照、接地同期|
|マップ統合|縮尺、ドット密度、接地影、遮蔽、光源、焦点、カメラ独立性|

検証用平面で確認した項目と、実マップ・実エンジンで確認した項目を区別する。
