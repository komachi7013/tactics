# 『澪を継ぐ者』音声v1 制作記録

2026-10-18。提供された `.codex/skills/rpg-music/SKILL.md`、`references/production.md`、`references/templates.md` と `docs/design/audio-contract.md` に従った音素材納品。ゲーム接続は統合担当の範囲。既存の技術確認用森曲・例示旋律・既存作品の曲を流用していない。

## 制作範囲と再現

独自作曲BGM3点、数式合成SE8点。音源はスキル内唯一の `GeneralUser-GS.sf2`、内部名2.0.3 BETA、SHA256 `9575028c7a1f589f5770fccc8cff2734566af40cd26ed836944e9a5152688cfe`。FluidSynth 2.6.1、既存macOS `afconvert`、Python標準ライブラリを使用。新規依存・有料サービス・外部通信なし。SoundFont自体は配信しない。

再現コマンドはプロジェクト直下で `.venv/bin/python scripts/build-game-audio.py`。既存の生成成果物がある場合は停止し、上書きしない。再現する場合は成果物を別途保護し、両出力先を空にすること。スクリプトは同じ音符・SE seed・処理を再現するが、FluidSynth/音源/OS変換器の版をまたぐPCMのビット一致は保証しない。採用ファイルのSHAは `metadata.json` が基準。

編集用JSONは音符/velocity/声部分離、MIDIはtempo/4拍子/programを含む。4周のMIDIを44.1kHz stereo PCM16でrenderし、残響が安定した3周目から8小節だけ切り出してsample peakを0.32へ調整。末尾の無音化や拍を重ねるクロスフェードは使用しない。会話/終幕は250ms、戦闘は270.6122449msだけ開始位相を回転し、同じ位相間の一周を使う。配信は22.05kHz stereo PCM16 WAV。BGMのループは最終デコードPCM全区間 `[0, frames)`、end exclusive。

## 音楽設計

共通モチーフ `river-record` v1 は D5–F5–E5 (MIDI74,77,76)、拍0/1.5/2.5、音価1.3/.7/.8拍。間の0.2/0.3拍と小節末0.7拍を休止し、水の流れと複数の記録が応答する静かな表情を意図する。鐘・歌・固有の物語装置を示す音は使わない。

## SE設計

全てオリジナル数式合成。最初0.7msのクリック予防、末尾15msの短いフェード、DC補正、master peak0.5。乱数は `2026101800` から一覧順に8seed。録音・第三者SE・生成サービス素材なし。

| ID | 尺 | 用途/材質 | アタック/本体/尾 |
|---|---|---|---|
| se-ui | 約90ms | 起動/防御/取消、控えめな確認 | 740/1110Hzの短い2倍音、急減衰 |
| se-move | 約150ms | 確定移動、石面一歩の抽象表現 | ノイズ接触/150Hz胴鳴り/短い摩擦 |
| se-impact | 240ms | 実ダメージ、鈍い接触 | 短いノイズ/94・213Hz衝撃/減衰 |
| se-heal | 約650ms | 手当確定 | 523/659/784Hzの順次応答、柔らかな尾 |
| se-record | 360ms | 採取/案内確定 | 紙の抽象ノイズ/880→1175Hz/短い尾 |
| se-mechanism | 約550ms | 水門/復旧指示確定 | 低域摩擦ノイズ/120・180Hzの金属的胴鳴り |
| se-victory | 1100ms | 勝利 | D4/F#4/A4/D5の短い上行和音 |
| se-defeat | 約1150ms | 敗北 | D4/C4/A3の穏やかな下降 |

同ID間隔80ms・SE3同時は接続側契約。SEは非ループなので境界連続性は対象外。移動中の全マス足音や材質分岐は今回作らない。

## 利用条件

SoundFontのRIFF INFOを `soundfont-info.json`、ICMT全文を `soundfont-license.txt` に抽出保存した。内包License v2.0は私用/商用の音楽制作を制限なく許可し、GeneralUser GSのサンプルについて音楽録音の収益化も許可すると記載。一方で作者自身が一部サンプルの由来を100%確認できないこと、制限サンプルが見つかれば置き換えたい旨も記載しており、その留保を削除していない。音声制作許諾と、音源データ自体の配布許諾は分けて扱う。今回はsf2をpublicへコピーしない。確認日2026-10-18、出典は実際に使用した音源内ICMT。公式連絡先は同ライセンスに記載。オリジナル音符・合成SE・処理スクリプトと、SoundFont/収録サンプルの条件は別。

## QAと調整履歴

音声生成・配信再デコード・尺/peak/RMS/DC/rail/loop数値検査は完了。11配信は合計8,714,244bytes。BGM loop framesは会話705600・戦闘661500・終幕705600。全11点でPCM上限到達0、DC絶対値0.005未満、無音ではない。sample peak/RMSを測定しており、true peak/LUFSは未測定。ffmpeg/ffprobe未検出。

修正3/3。未採用の過去試作は開発用バックアップに保管し、作業ツリーから整理済み。採用済みの楽譜・MIDI・master・配信PCMは保持している。

1. 初回のSE配信先頭がafconvert再サンプル後129PCM (約0.00394) となり、過剰に厳しい100PCM未満の診断で処理停止。診断を0.01 full-scale未満(327PCM)へ変更した。SE実音声をこの診断のために加工していない。同時にBGM小節頭のアタックが20ms RMS差警告となるため、残響が安定した250ms位相へ一周切出しを回転。
2. 戦闘の左境界差0.02643が目安0.02を超えたため、1/8〜2/5秒内で同じ音楽位相間の振幅・傾きが近い切出し位置を選ぶ処理へ変更。音符や8小節の周期を変更しない。
3. 音域点検で、戦闘主旋律のA3が通常の長笛下限を下回ると判明。同じ旋律/尺を低音域に適するGMクラリネットへ変更し、戦闘曲だけ再render。最終の数値loopフラグは3曲とも空。最終SHAはmetadataに保存。

**聴感・ゲーム内音声確認は未実施。** 数値警告0を自然なループ・良好な演奏・適切な音量・材質識別の合格とは扱わない。検証用の3周連結WAVと4周render WAVは作業ツリーから整理済み。必要なら楽譜/MIDI/masterまたは開発用バックアップから再作成できる。SE単独/連続発火、BGM+最大同時SE、音量/ミュート/場面切替/隠れたタブ、実ブラウザー再生は統合担当による確認待ち。実保存・既存タブ・QA操作を音素材担当は行っていない。
