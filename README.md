# 澪を継ぐ者 — 流域盟約戦記

TypeScript・Phaser・Viteによるターン制SRPG。全12ステージと終幕、戦闘開始/勝利時の保存、編成・成長・装備を実装しています。

## 開発

```sh
npm ci
npm run dev
```

Node.js 24系で確認しています。開発サーバーは127.0.0.1のみで起動します。

```sh
npm test
npm run test:cua
npm run typecheck
npm run build
```

`npm test`はゲームの回帰テストと正規AIのシナリオ再生です。`test:cua`は再利用する入力確認ヘルパーのNodeテストで、ブラウザー実機検査とは別です。`test:all`は両方を順に実行します。Vitestの同時実行は2ワーカーに制限しています。

## 構成

- `src/domain/`: 戦闘ルール・AI。表示処理と分離しています。
- `src/view/`: 盤面、移動/攻撃演出、会話、ステータス。
- `src/landscapes/`: 全12面の地形・配置と景観登録。
- `src/qa/`: 開発時の保存隔離と、通常回帰テストで共有する状態構築。名前だけを理由に削除しないでください。
- `tests/`: 自動テスト、固定乱数・正規AIの再生fixture。
- `tools/cua/`: 再利用する入力確認ヘルパーとそのテスト。
- `scripts/`: テストfixtureの経路探索と素材/音声の生成・検査。
- `public/`: 採用済みの配信素材。`assets/motion-v1/`が四方向歩行・自然停止と顔素材です。
- `assets/`: 編集用の採用音源、ライセンス、景観の元画像。
- `generated_images/`: provenanceまたは残した素材処理から参照する元画像のみ。
- `.codex/skills/`: 素材制作のローカル手順・ツール・音源利用条件。
- `docs/design/`: 企画・採用仕様。実装の現状はコードと自動テストを優先してください。

`node_modules/`、`.venv/`、`dist/`はローカル依存環境/ビルド出力としてGit対象外です。Python素材制作には既存`.venv`とローカルスキルを使用します。

## 現在の表示仕様

人物は前後左右それぞれ4コマの歩行と自然停止を使用します。避難民は静止、護送車は移動中だけ車輪を回します。代表とトマは別デザインです。通常は180ms/マス・90ms/コマで、戦闘ルールと表示方向を分離しています。

攻撃演出の短縮は一時無効です。保存値・省モーション設定・手動操作では有効化できません。「移動演出を短縮」は移動だけに適用し、通常攻撃の時間・結果・操作復帰を維持します。

## 保存・検証

進行はブラウザーのlocalStorageキー`mio-tactics.progress.v1`へ保存します（ペイロードversion4）。戦闘途中のHP/位置は保存せず、再開は戦闘の初期状態です。開発用`?qaSession=<識別子>`は別保存先を使います。通常保存や他のQA状態と混同しないでください。

今回の整理ではゲームを再プレイしていません。整理前に両ブラウザーの全12面QAは完了済みで、今回の確認は参照・自動テスト・型検査・ビルドです。過去のスクリーンショット、ログ、比較ハーネス、未採用試作は作業ツリーから整理し、元の`tactics.bak`を変更せず保持しています。

音源の出典・利用条件は[制作記録](assets/audio/v1/production.md)と[SoundFontライセンス](assets/audio/v1/soundfont-license.txt)、仕様は[設計資料](docs/design/README.md)を参照してください。
