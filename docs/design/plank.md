## 原案と現状

- [原企画§4](game-plan.md): 水工師の機動支援。「射程1の味方の次の移動に限り浅瀬費用1、戦闘2回。通行不能地形は作らない」。これらの数値も原企画では本編用の**候補数値**。今回まずこの候補を維持する案であり、新規の数値設定ではない。
- 原企画§4/§6では第2章に開放、イヴァは水工師。現行はイヴァB04から編成可。技は人物永久能力でなく主職の能力とする既存[職技契約](job-commands.md)。受動補助「水路歩き」は別機能で、渡り板を習得/継承済みとは扱わない。

- 移動は`reachable`が浅瀬の各進入セルに`Unit.shallowCost`を加算、乾地は1。上下左右・高さ差1以内・blocked/占有の拒否は既存ルール。現在のundoは移動後かつ行動前だけ、移動元へ戻す。攻撃/回復等を行った後はundo不可。
- `Campaign`は戦闘開始/結果・育成/職/編成を保存し、戦闘盤面や技の途中状態を保存しない。v2は未知の最上位キーを拒否する。既存「再開」は途中復元でなく初期配置からの再出撃。

## ユーザーへの一括相談案

**「渡り板は原案の射程1・浅瀬費用1・戦闘2回で、次のおすすめ一式にしてよいですか」**の1問にまとめる。個別変更の希望があれば該当項目だけ変更できる。順番の承認で以下を自動確定しない。

1. **他の生存味方戦闘員だけ**。自己・敵・退避者・荷車/トマ/一行など自動護送NPCは対象外。上下左右に隣接し、高さ差1以内。高さ差1は原案の射程1だけからは確定せず、既存護衛と同じ渡し方にする**追加案**。射線判定は加えない。
2. **1行動を使い、付与確定で使用回数を1消費**。1行動は渡り板の原表にはなく既存職技に合わせる**追加案**。移動済みでも未行動なら使用可、使用後の移動も既存どおり可。対象選択/確認の取消・不正対象は消費しない。
3. **対象の次の合法な移動確定まで持続**。移動せず起動終了/ラウンド経過しても残り、付与者が退避しても残る。既に起動済みの味方にも次回用として付与可。次の移動が乾地だけでも消費する（「次の移動」を浅瀬通過時まで温存と読み替えない）。対象退避・戦闘終了で破棄。付与者退避時の扱いは原案未定の**追加案**。
4. **移動取消で効果を戻す**。適用された移動を既存の「移動を取り消す」で合法に戻せた場合は、位置と渡り板効果を両方復元。イヴァが既に使った回数は返さない。移動先プレビューや同一セル/不正移動では効果を消さない。
5. **重複・無効な付与は拒否**。既に渡り板が付いた味方、元から浅瀬費用1の味方（斥候/水路歩き等）には使用不可・行動/回数不消費。後者は無駄打ちを防ぐ**追加案**。既存浅瀬適性と足し算して0以下にしない。

この一式なら、護送速度を変更せず、移動取消の自由を保ち、味方を水路へ送り出す役割を作れる。代案は自己使用可・次起動末で失効・既存浅瀬適性にも使用可などだが、それぞれ水工師本人の機動力、温存の余地、無駄打ち可否を変えるため黙って採用しない。

## 通常の技術的補完案

以下は上記の遊び方が決まった後の実装方法。公開ルールに新たな能力値・通貨・解放条件を増やさない。

| 層 | 最小の変更候補 | 維持する契約 |
|---|---|---|
| domain/types | command/jobCommandに渡り板、Unitに戦闘内残回数と効果、activationにundo用の消費前情報（名前は実装時に選定） | 必須追加fieldで既存fixture/全コマンドを壊さない。任意fieldの初期化/除去を列挙 |
| engine | 共通の有効浅瀬費用をreachableから使用、付与previewとreduceの合法性共有、move消費とundo復元 | base shallowCostを直接書換えず、UI予告/実移動/AIが同じ到達関数を使う。水位・高さ・通行可否・占有・移動力は変えない |
| undo/起動 | 合法moveの直前効果をactivationへ記録。undoでその効果だけ復元。start/end/restartでundo情報を初期化 | 行動後は既存どおりundo不可。効果を消費していない移動のundoで新たな効果を作らない。移動で即勝利後はundo不可 |
| jobs/party | 既存applyJobsで旧戦闘payloadを消してから、主職engineerだけ2回を初期化 | 測線/護衛/手当・主職復帰・受動補助は既存契約。準備中に使用済み回数を継承しない |
| main/UI | 対象選択→予告/確認→確定、回数/対象効果/無効理由を表示。経路費用は共通関数結果 | 選択だけでは消費しない。追加購入画面・新装備枠・専用画像は不要。移動後に効果が消えたことを表示 |
| presentation/BattleFlow | 付与自体は現行測線/護衛と同じく移動/攻撃planなし→即座に状態表示。移動/取消の経路再構築は個別確認 | 効果はdomainで一度commitし、演出終了で再適用しない。必要なくBattleFlowや敵timerを変更しない |

付与者IDを寿命条件にしない一式なら、対象効果は簡単な有無情報で足りる。ログ用の由来と効果有効性を混同しない。対象退避の清掃は通常HP0処理の共通経路で確認し、付与者退避時の護衛解除に巻き込まない。

`src/view/presentation.ts`のundoは消費後のbefore状態で元経路を再探索する。渡り板で伸びた浅瀬経路は通常費用では移動力超過となり、現方式のままだと取消の戻りplanを作れない可能性がある。実装時はundoで復元した効果を使って元位置から再探索するか、実移動経路を戦闘内に保持して逆順利用する。最小変更は前者が候補だが、実際に移動した経路との一致を確かめて選ぶ。位置復元が成功するだけでこの表示経路を検証済みにしない。これは既存版で発見した確定不具合ではなく、新効果導入時の影響である。
