# シナリオシーンの演出計画

2026-11-06 実装済み。序章・全12章・終幕を共通のシナリオ再生画面で表示する。

- 序章、第1章〜第12章、エピローグのすべてのシナリオシーンに、場面に合ったアニメ絵の背景を用意する。章のシナリオシーンも戦闘画面を背景にしない。
- 語りは画面中央に表示し、文字の背後に薄い黒を敷いて読みやすくする。タップまたはクリックで次へ進む。
- キャラクターの会話は、現在の顔画像と会話文の表示を引き継ぐ。
- 序章は「序章：水が残した記録」の章題を表示してから、語りと会話へ進む。
- 序章の終了後は「1章：消された水位 〜トルネ渡し場〜」の章題を表示してから、会話シーンへ進む。
- シナリオ終了後に戦闘画面へ切り替える。戦闘中に発生する短い会話と、章のシナリオシーンは区別して扱う。

背景は `public/assets/story/` の14枚。序章には流域全体を見渡す絵、1章には渡し場の絵を用意し、2章〜12章と終幕にもそれぞれ舞台に合う絵を用意した。生成経路は `image_gen`（`art_source: host_image`）。プロンプトと素材一覧は同ディレクトリの `provenance.json`、元のPNGは `output/story-scenes/originals/` に保存する。

章題もクリック・タップで本文へ進む。本文は自動で送らず、戻る・キーボード操作・スキップ・読み返しに対応する。最終ページはラベル付きボタンで戦闘説明または結果画面へ進む。戦闘中の短い会話は従来どおり盤面を背景にする。

動きを減らす設定では背景のズームと表示時のアニメーションを止める。背景画像が読み込めなくても本文と操作は維持する。

2026-11-06 追記：すべてのシナリオは章題→語り→会話の順とする。それぞれの中では台本の順を保つ。枠の寸法とボタンの位置は、文章量や話者によって変えない。1章冒頭の杭と公図に関する台詞は、リセの名前と顔画像を明示する。
