# 育成・編成 v2 作業契約

2026-10-18。ユーザー承認「任意控えには訓練点を付与しない／強制離脱は復帰補填」「主人公必須＋仲間3人」を基準にライブ実装する。従前の全員同額案は不採用。正式名はリセ・アーヴェン。

制作: growth_v2（成長純粋関数）、jobs_party_v2（職業・初期配置）、campaign_growth_v2（保存・移行）、親（DOM統合・設計・受入）。独立レビューは別担当へ版を固定して委任。レビュー修正上限3回、旧工程の履歴は保持。

## 可逆な試作値と採用理由

- 必須戦の初回クリア:出撃した本人に各2点。HP0の退避者も出撃に含む。NPCを除外。初回出撃履歴を固定し再戦で配り直さない。
- 任意控えは0点。ネイアの物語上のB06強制不在のみ、B07への復帰時に2点を一度補填。B05で任意に控えた分は補填しない。
- 章完了ごと共通レベル1→2→3→4→5。各レベルにつきHP+2/攻撃+1、防御/移動不変。調整値は初見評価未済。
- 補習比較:無制限再戦報酬は周回前提と二重付与を招く。主力から移す方式は育成の巻戻しを招く。採用する段階補習は完了章数×6点まで各人の総獲得点を手動で引き上げる。既得点を減らさず同じ上限で反復しても加算なし。章途中では出撃報酬が先行し、章末に控えが追いつける。加入者も利用可、未加入・強制離脱中は不可。
- B01/B02は加入者3人のため3人出撃が例外。B03からリセ＋仲間3人。セナB03は臨時同行、イヴァB04は臨時同行、ダニはB04合流後B05から選択可能。ネイアB06のみ不可。過去戦再戦はその時点の加入・離脱状況を再現する。
- 主職1＋他職の習得済み支援1、拠点で無料振り直し。まず測量官/堤防衛士間の変更と各人初期職への復帰、6職の受動支援を小さく接続する。原企画の職業固有コマンド2〜3種の完成を意味しない。
- 旧v1保存は実際の旧固定編成から初回履歴を復元し、既得進行・証拠を保持。読取だけで保存を書き換えない。不正/未知保存を保護。保存競合で初回編成や育成編集を黙って上書きしない。

## 検証・範囲

出撃制約、任意控えと強制不在、再戦重複、復帰冪等性、補習上限、学習費用/継承/振直し、旧保存移行、進行保持、12戦回帰を自動試験。GUIは座標入力ウィンドウ解決エラーで停止中、実機未確認。音操作を行わずユーザーのミュートを解除しない。再読込後も初期音オフの既存動作を保持。

独立試作設定は/tmp/tactics-progression-v2配下。プロジェクトtsconfig/Vite/依存設定は追加変更しない。ライブ変更前のhashとViteログ位置はbefore.json、変更後の通知差分を別記録。実ブラウザの途中状態・保存値・ミュートは未観測であり、実保存への影響なしと断定しない。
