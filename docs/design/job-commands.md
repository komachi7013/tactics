# 職固有コマンド v1 契約

2026-10-18。ユーザーは既存企画に沿う次の最小単位・独立レビュー後のライブ統合を承認。司令塔とGame Studio Phaserを適用し、制作候補をVite監視外 `/tmp/tactics-job-commands-v1` に置く。ライブ変更前に独立レビューする。Pythonはプロジェクト .venv/bin/pythonのみ。

## 先行範囲

原企画§4の測線・護衛を主職固有コマンドとして先行する。施療士の手当、斥候の弩・浅瀬適性を再利用。主職に付随する基本技なので新たな訓練点購入/解放条件は増やさない。継承支援は既存の受動効果1つだけで、技/残回数は継承しない。職変更は既存の測量官/堤防衛士と本人初期職への復帰を維持。

- 測線: 他の生存味方戦闘員、Manhattan距離1〜3、既存の地形射線。自己・敵・退避者・攻撃しない護送NPCは対象外。1行動・本人戦闘2回。対象の次の合法な通常攻撃+2。既存効果を上書き/重複できない。無効行動は消費しない。
- 護衛: 他の生存味方に隣接・高さ差1以内、護送NPCも可。1行動、原案に使用回数制限なし。対象の次の被ダメージ−2、発動元の次起動または退避まで。通常防御と非加算で大きい方だけ。既存護衛を上書きできない。合法な被攻撃で一度消費、無効攻撃では保持。
- 消費/効果はBattleState/Unitの戦闘中派生情報だけ。セーブ形式v2と訓練点/職保存に追加しない。再挑戦・戦闘再開は現主職から回数を初期化する。
- AIは既存attackPreviewと同じ補正後ダメージを使う。敵の主職や新技自動使用を新設しない。水門・記録・必須目標の操作権を職で制限しない。

水工師の渡り板、記録官の読令は次の縦切りへ残す。読令には同じAI評価による候補再計算と有効性の実証が必要なので、今回の二職へ混ぜない。装備は品目/性能が未定のため追加しない。原企画の固定武器の扱いを維持。

## 役割と受入

job_command_engine: types/engineと境界試験。job_command_assignment: 現主職の技付与/保存互換/全12戦回帰/正規技使用の勝利。親: DOM対象選択/確認/残数/効果表示、統合と再読込記録。独立reviewは別担当で読取専用。修正は本ゲート最大3回。

無効操作・消費・射程/射線・起動/退避/攻撃の効果寿命・防御非加算・AI評価・v1/v2保存互換・既存全12戦/成長経路を試験。測線を自分の直接攻撃が届かない位置から味方へ渡して使う局面を正規コマンドで示す。GUIはnoWindowsAvailableで停止中、実機受入と数値/初見評価は分離する。ミュート解除/試聴/実ブラウザ保存操作/サーバー再起動/依存追加/公開pushなし。
