# プレイヤーの操作（2026-11-06）

- 記録・宝箱・水門弁・操作盤・補助弁・救助対象のあるマスには移動できる。隣接マスから取得・操作はできない。
- 移動演出が終わった後、その場所で取得・操作が可能なら確認画面を自動で開く。「確定」するまで戦闘状態を変更しない。
- 「キャンセル」は移動後の位置を保つ。そのマスを選び直すと再確認できる。取得・操作の専用コマンドボタンは表示しない。
- 同じ人物の手番で、移動を一度、攻撃か技を一度、宝箱か記録の取得を一度行える。攻撃・技と取得は別枠で、順序は自由。宝箱と記録は取得枠を共有する。水門操作・復旧・救助・防御などは従来通り攻撃や技と同じ枠。
- 移動を取り消すと、その移動後の取得・操作・救助・復旧も取り消し、宝箱・記録・水門・使用回数を移動前に戻す。移動前に済ませた取得や攻撃は残す。移動後に攻撃や技、防御を使った場合はその移動を取り消せない。
- 床が重なる場所もマップ上で選ぶだけで移動する。床切り替え・移動確認の追加ボタンは表示しない。
- 全ステージでマップをマウスの左ドラッグで上下左右にスクロールできる。ドラッグ後の離した場所は選択しない。小さな手ぶれは通常クリックとして扱う。タッチのスワイプとホイールによるスクロールも維持する。
- 荷車は護送する人物として扱い、同じマスに味方を重ねない。「荷車を押す」はすぐ隣の味方が使う。
- 移動先・攻撃対象・技の対象を選んでいる間は、その選択を取り消すボタン以外のコマンドを無効にする。「戻る」は設けない。
- 技ボタンには実際の技名を表示する。常時発動する技は無効表示にする。技の説明と進行案内は、左下の案内欄に一つだけ表示する。
- 音は初期設定でオン。ブラウザの再生開始は最初のクリック・キー操作に合わせる。オン・オフと音量は「操作・設定」から変更する。タイトルや確認画面には音の設定や診断情報を置かない。

移動後の確認は戦闘表示の継続処理が終わってから開く。別の戦闘へ切り替わった場合や再開始した場合、古い到着確認は破棄する。
